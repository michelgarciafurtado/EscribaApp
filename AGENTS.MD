# Instruções para o agente

Você auxilia no desenvolvimento desta aplicação .NET.

## Documentação

Antes de implementar uma tarefa, leia:

- .agent/contexto.md
- .agent/arquitetura.md
- .agent/padroes-codigo.md

Consulte conforme a tarefa:

- .agent/regras-negocio.md
- .agent/testes.md
- .agent/tarefas/tarefa-atual.md

## Forma de trabalho

- Examine o código existente antes de propor alterações.
- Respeite as convenções já adotadas no projeto.
- Implemente somente o necessário para a tarefa.
- Não adicione dependências sem justificar sua necessidade.
- Não inclua senhas, tokens ou credenciais nos arquivos.
- Execute os testes relevantes quando houver alteração de comportamento.
- Ao concluir, informe o que mudou e como foi verificado.
